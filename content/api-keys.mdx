# How to get your API key

Welcome! This guide explains step by step how to get your API key.

## Getting your API key

<Steps>

### 1. Create your account on Ikalas

Go to [https://ikalas.com](https://ikalas.com) and create your user account.

### 2. Access the dashboard

Once logged in, go to [https://dashboard.ikalas.com](https://dashboard.ikalas.com)

### 3. Navigate to the API section

In the dashboard, click on the **"API"** tab or go directly to [https://dashboard.ikalas.com/\_api](https://dashboard.ikalas.com/_api)

### 4. Create your API key

In the API section, you'll see a **"New"** button. Click on it to generate your API key.

### 5. Copy and save your key

Your API key will be displayed in a format similar to: `IK-_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

⚠️ **Important**: Save this key in a safe place. It will no longer be visible after leaving the page.

</Steps>
