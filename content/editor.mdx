# Cheat Sheet

Some useful information to help you navigate the API.

| API Endpoint                           | Description            |
| -------------------------------------- | ---------------------- |
| `https://ikalas.com/api/v1`            | Base URL for API calls |
| `https://ikalas.com/api/v1/api-llm-ia` | URL for AI API calls   |

| URLs                                | Description                          |
| ----------------------------------- | ------------------------------------ |
| `https://dashboard.ikalas.com/_api` | To create and retrieve your API keys |

## Authentication

Include your API key in all requests. Your API key is here: [https://dashboard.ikalas.com/\_api](https://dashboard.ikalas.com/_api)

## Request and Response Formats

The Ikalas API uses JSON for all requests and responses. Make sure to include the `Content-Type: application/json` header in your requests.

Example request:

```json
{
  "system": "You are a useful assistant",
  "prompt": "USA independance date",
  "models": "meta-llama/llama-3.3-70b-instruct:free",
  "response_format": "default"
}
```
